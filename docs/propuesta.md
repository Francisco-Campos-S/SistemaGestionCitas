##3.Problema
La gestión manual de citas genera desorden en los horarios, pérdida de información de los usuarios y duplicidad de registros, lo que compromete la eficiencia operativa.

## 4. Justificación
Desarrollar una aplicación de escritorio en C# con Windows Forms permitirá automatizar el agendamiento y la consulta de citas de manera intuitiva y estructurada.

## 5. Usuarios
* *Recepcionistas / Administradores:* Encargados de registrar, consultar, modificar y cancelar las citas.

## 6. Objetivo General
Desarrollar una aplicación de escritorio utilizando C# y Windows Forms que permita la administración eficiente de citas y servicios.

## 7. Objetivos Específicos
* Diseñar una interfaz gráfica intuitiva con un formulario principal y navegación fluida.
* Implementar listas y colecciones en memoria para el almacenamiento de los datos.
* Aplicar validaciones de entrada de datos para evitar valores nulos o incoherentes.

## 8. Alcance
Este primer avance incluye la propuesta técnica en Markdown, el diseño del menú principal, la interfaz de registro y la gestión temporal de citas en listas en memoria.

## 9. Fuera de Alcance
Conexión a bases de datos relacionales externas (como SQL Server) y generación de reportes físicos para esta primera entrega.

## 10. Funcionalidades (Avance 1)
* Menú principal de navegación.
* Formulario para registrar citas preliminares.
* Almacenamiento en listas en memoria.
* Limpieza de controles y confirmación para salir del sistema (MessageBox).

## 11. Distribución Inicial de Tareas
* *Integrante 1:* Documentación técnica y archivo propuesta.md.
* *Integrante 2:* Control de versiones en Git/GitHub y respaldo .zip.
* *Integrante 3:* Diseñador de formularios e interfaz gráfica en Windows Forms.
* *Integrante 4:* Programación de eventos, limpieza de controles y salida del sistema.
* *Integrante 5:* Manejo de listas en memoria y lógica de negocio.
